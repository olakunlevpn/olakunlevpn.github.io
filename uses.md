The tools I actually reach for. Not a wishlist, just what's open on my machine most days.

## Editor and terminal

VS Code for almost everything, with a couple of Laravel and PHP extensions doing the heavy lifting. PhpStorm when a refactor gets serious. iTerm2 with zsh, and Laravel Herd running my local sites so I'm not babysitting a stack.

## Languages and frameworks

PHP and Laravel are home base. Livewire and Filament when the admin side needs to move fast. On the front end it's JavaScript with Vue, some React, and Node where a small service makes sense. Tailwind for styling, because writing custom CSS twice is a tax I stopped paying.

## Cloud and infrastructure

AWS for the serious stuff: Lambda, S3, DynamoDB, API Gateway, SQS and SNS when things need to talk without blocking. CloudWatch to see what's happening, IAM to keep it locked down. For smaller projects, a plain VPS and a deploy script beats a control plane I have to think about.

## Everyday tools

Git and GitHub for everything, down to notes I don't want to lose. TablePlus for databases. Postman for poking APIs. And a pile of small skills and scripts I've built up over the years so the boring parts run themselves.

## Hardware

A Mac, an external monitor, a mechanical keyboard I'm quietly attached to. That's the whole setup. The work is in the head and the repo, not the desk.
